# Mockups — designprosjektets HTML, speilet til repo

Kenneth-regel 2026-09-06: mockup-HTML-er som refereres i designnotater/ordrer legges ved
leveransen og speiles hit, så designgaten kan sammenligne mot selve fila — ikke bare de
tekstlige designlås-punktene.

- Filene er `.dc.html` og trenger `support.js` (ligger her) i samme mappe for å åpnes i
  nettleser. Åpne direkte fra disk — ingen server nødvendig.
- **Designprosjektet er fortsatt arbeidsflaten** (repo-førings-regelen): endres en mockup
  der, følger ny kopi med neste leveranse. Kopien her er referanse for gate/ordre, ikke
  redigeringsflate.
