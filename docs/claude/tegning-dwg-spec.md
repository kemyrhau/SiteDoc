# DWG-tegninger ende til ende — libredwg

> Hjemmel: **Kenneth 2026-10-08:** *«er støtte for dwg også implementert?»* → *«ja, bestill spec hos fabel, libredwg»*.
> Konverterer = **libredwg** (åpen kildekode, ingen lisensavtale; ODA valgt bort). Orkestrators måling (develop `d17ec77b`)
> + fabels/agentens måling under. **Alt under er spesifikasjon.** Bygger på T1 (`feat/tegning-serieopplasting-t1`),
> som alt starter DWG-konvertering ved opprett OG ny revisjon via felles `startTegningKonvertering`.

## 0. Hva dette er, og ikke er

Én kjede: fil inn → DXF → SVG med riktige enheter → tegning som kan vises, måles, georefereres og snappes på — på web og
mobil. Rører **ikke** 3D/IFC/punktsky (egen chat), PDF-veien (virker), eller tegningsserie/T2.

### RETUR 2 (2026-10-09, branch `feat/dwg2-retur2`) — løser de åpne punktene fra RETUR 1

- **Rotasjon (vedtak A, Kenneth «A rett opp automatisk … som PDF-en»):** auto-rotasjon fra to signaler — veggvinkel (lengdevektet histogram mod 90°, terskel ≥ 60 % innenfor ±1°) gir aksejevnhet, tekstrotasjonene løser 90°-kvadranten (`velgAutoRotasjon`). Rotasjonen BAKES inn i SVG-koordinatene (`roterPunkt` i `dxfTilSvg`), mens TEXT/MTEXT/ATTRIB beholder sin egen rotasjon → **motroteres, står vannrett som arkitektens PDF**.
